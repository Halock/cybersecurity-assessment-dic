# Three-Year Cybersecurity Security Roadmap

## Defence Intelligence College (DIC)

**Project:** CCC299 Capstone Project
**Prepared by:** Adeshina Kolawole Tajudeen

---

## 1. Purpose

This roadmap translates the cybersecurity assessment findings into a phased security-improvement program.

The roadmap focuses on strengthening people, processes, technology, governance, and continuous security validation.

> **Portfolio Note:** This is a sanitized public representation. Specific operational details, sensitive infrastructure information, and confidential implementation information have been excluded.

---

# 2. Strategic Objectives

The roadmap is designed to:

1. Strengthen cybersecurity resilience.
2. Improve cybersecurity workforce capability.
3. Improve visibility of externally exposed assets.
4. Strengthen security validation.
5. Improve security monitoring and threat detection.
6. Improve governance and compliance management.
7. Support continuous cybersecurity improvement.

---

# 7. Key Performance Indicators

The following measures can be used to monitor progress:

### Workforce

* Number of cybersecurity professionals trained
* Number of relevant professional certifications
* Security-training completion rate

### Awareness

* Phishing-simulation performance
* Security-awareness participation
* Incident-reporting performance

### Security Operations

* Mean Time to Detect (MTTD)
* Mean Time to Respond (MTTR)
* Security findings identified and remediated
* Threat-hunting activities completed

### Governance

* Risk-register review frequency
* Compliance-monitoring coverage
* Security-policy review completion
* Executive security reporting frequency

### Resilience

* Security-validation exercises completed
* Remediation completion rate
* Recovery exercises completed

---

# 8. Implementation Principles

The roadmap should be implemented according to the following principles:

### Risk-Based

Security investments should be prioritized according to identified risk.

### Continuous

Security should be treated as an ongoing process rather than a one-time assessment.

### Measurable

Progress should be monitored through defined performance indicators.

### Sustainable

Security improvements should consider people, processes, technology, and organizational capability.

### Framework-Aligned

Security improvements should remain aligned with recognized frameworks and applicable regulatory requirements.

---

# 9. Governance and Review

The roadmap should be reviewed periodically to account for:

* Changes in the threat landscape
* New technologies
* Organizational changes
* Security incidents
* Regulatory requirements
* Changes in identified risks
* Results of security assessments

The risk register should be updated as remediation activities are completed and new risks emerge.

---

# 10. Conclusion

The three-year roadmap provides a structured approach for transforming cybersecurity assessment findings into measurable security improvements.

The roadmap progresses from **strengthening foundational capabilities**, to **expanding security validation**, and finally to **automating and maturing governance and security operations**.

This approach supports continuous improvement while maintaining focus on organizational risk, cybersecurity resilience, workforce capability, and effective security governance.
