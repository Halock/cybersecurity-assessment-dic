## 1. Purpose

This document summarizes how the cybersecurity assessment relates to the **CIS Critical Security Controls v8**.

The CIS Controls provide a prioritized set of security practices that can help organizations reduce common cybersecurity risks and improve defensive capability.

# 3. Asset Inventory and Management

The assessment considered the organization's approach to identifying and managing information assets and technology resources.

### Improvement Opportunities

* Maintain accurate asset information.
* Periodically review asset inventories.
* Improve visibility of externally exposed assets.
* Integrate asset information into risk-management processes.

---

# 4. Data Protection

The assessment considered controls supporting the protection of organizational information.

Key areas included:

* Access control
* Information handling
* Authentication
* Security awareness
* Data-protection governance

### Improvement Opportunities

* Continue strengthening information-protection practices.
* Maintain appropriate access restrictions.
* Review information exposure periodically.
* Support data-protection compliance.

# 5. Secure Configuration

The assessment considered the importance of secure configuration of systems and infrastructure.

### Improvement Opportunities

* Maintain secure configuration standards.
* Conduct periodic configuration reviews.
* Validate security controls after significant changes.
* Maintain appropriate system-hardening practices.

# 6. Account Management

The assessment considered:

* User accounts
* Authentication
* Access privileges
* Identity management
* Security awareness

### Improvement Opportunities

* Continue strengthening authentication controls.
* Periodically review user privileges.
* Maintain strong account-management processes.
* Monitor for suspicious authentication activity.

---

# 7. Access Control Management

The assessment considered whether access to systems and information is appropriately controlled.

### Improvement Opportunities

* Apply least-privilege principles.
* Periodically review access rights.
* Maintain strong authentication.
* Remove unnecessary or inactive access.

---

# 8. Vulnerability Management

The assessment considered the organization's approach to identifying and managing cybersecurity weaknesses.

### Improvement Opportunities

* Maintain periodic vulnerability assessments.
* Prioritize remediation according to risk.
* Validate remediation activities.
* Conduct recurring security testing.

# 9. Audit Log Management

### Improvement Opportunities

---

# 15. Continuous Improvement

The CIS Controls can support a continuous security-improvement cycle:

**Identify → Protect → Monitor → Respond → Improve**

Security controls should be periodically reviewed to ensure they remain appropriate as technology, threats, and organizational requirements change.

---

# 16. Conclusion

The CIS Controls mapping demonstrates how prioritized security practices can be applied to an enterprise cybersecurity assessment.

The assessment identified established security capabilities while also highlighting opportunities to strengthen workforce capability, external exposure monitoring, vulnerability management, network monitoring, and continuous security validation.
