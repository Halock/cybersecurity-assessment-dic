## 1. Purpose

This document summarizes how the cybersecurity assessment was mapped to the **NIST Cybersecurity Framework (CSF) 2.0**.

The mapping demonstrates how identified security practices and improvement areas relate to the six core NIST CSF functions:

* Govern
* Identify
* Protect
* Detect
* Respond
* Recover

> **Portfolio Note:** This is a sanitized public representation. Sensitive operational information, confidential evidence, and detailed infrastructure information have been excluded.

# 2. NIST CSF 2.0 Mapping

| NIST Function     | Assessment Focus                                                        | General Assessment |
| ----------------- | ----------------------------------------------------------------------- | ------------------ |
| **Govern (GV)**   | Cybersecurity governance, policies, responsibilities, risk management   | Mature             |
| **Identify (ID)** | Asset awareness, risk assessment, organizational context                | Mature             |
| **Protect (PR)**  | Access control, authentication, security awareness, protective controls | Highly Mature      |

# 3. Govern (GV)

## Assessment Areas

The assessment considered:

* Cybersecurity policies
* Organizational responsibilities
* Risk-management processes
* Security governance
* Compliance requirements
* Workforce responsibilities

## Observations

The assessment indicated an established governance structure supported by documented security policies and defined cybersecurity responsibilities.

### Improvement Opportunities

* Improve automation of governance processes.
* Strengthen executive security reporting.
* Improve continuous risk-register management.
* Enhance compliance-monitoring capabilities.

# 4. Identify (ID)

## Assessment Areas

The assessment considered:

* Organizational risk
* Information assets
* Security dependencies
* Threat exposure
* Risk-management processes

## Observations

Risk identification and assessment processes were established.

The enterprise risk assessment provided a structured method for identifying, scoring, and prioritizing cybersecurity risks.

### Improvement Opportunities

* Maintain updated risk information.
* Improve automated asset and risk tracking.
* Continue periodic security assessments.

# 9. Overall Assessment

The assessment indicated that the organization had established cybersecurity governance and multiple layers of security controls.

The principal improvement opportunities were associated with:

1. Cybersecurity workforce capacity
2. External attack-surface visibility
3. Continuous security validation
4. Security governance automation
5. Ongoing security-assurance activities

The NIST CSF was used as a structured framework for identifying these improvement opportunities.

# 11. Conclusion

The NIST CSF 2.0 mapping demonstrates how cybersecurity governance, risk management, protective controls, detection, response, and recovery activities can be evaluated as part of an enterprise-wide security assessment.

The framework also provides a foundation for continuous improvement and future cybersecurity maturity assessments.
