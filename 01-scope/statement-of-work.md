## 1. Project Overview

This project involved conducting a structured cybersecurity and security-risk assessment of an institutional environment.

The assessment evaluated cybersecurity governance, technical and operational security controls, physical security considerations, human-factor risks, publicly exposed information, and overall organizational resilience.

The assessment was designed to identify security gaps, evaluate associated risks, and develop practical recommendations aligned with recognized cybersecurity frameworks and data-protection requirements.

> **Portfolio Note:** This document is a sanitized public representation of the original academic assessment. Sensitive operational information, confidential evidence, credentials, detailed infrastructure information, and exploitable security details have been excluded.

## 2. Assessment Objectives

The primary objectives were to:

1. Assess the organization's overall cybersecurity posture.
2. Identify potential cybersecurity and physical-security risks.
3. Evaluate human-factor and security-awareness risks.
4. Assess publicly available information using OSINT techniques.
5. Review security governance and operational practices.
6. Evaluate alignment with recognized cybersecurity frameworks.
7. Develop a structured enterprise risk assessment.
8. Provide practical recommendations for improving security resilience.
9. Develop a phased strategic cybersecurity improvement roadmap.

---

## 5. Risk Assessment Approach

A qualitative **5 × 5 likelihood-impact risk matrix** was used.

Risk was calculated using:

**Risk Score = Likelihood × Impact**

Risk categories were classified as:

| Risk Level | Score Range |
| ---------- | ----------: |
| Low        |         1–4 |
| Medium     |         5–9 |
| High       |       10–16 |
| Critical   |       17–25 |

The assessment identified:

| Risk Level | Number of Findings |
| ---------- | -----------------: |
| Critical   |                  0 |
| High       |                  3 |
| Medium     |                  5 |
| Low        |                  2 |
| **Total**  |             **10** |
