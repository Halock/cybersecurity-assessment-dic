## Project Overview

This repository documents a comprehensive cybersecurity and security-risk assessment conducted as part of the **CCC299 Capstone Project** for the Defence Intelligence College (DIC).

The assessment evaluated the organisation's security posture across physical security, cybersecurity governance, human factors, wireless security, incident response, publicly exposed information, and organisational resilience.

The assessment was structured around established cybersecurity and information-security frameworks, including:

* NIST Cybersecurity Framework (CSF) 2.0
* ISO/IEC 27001:2022
* CIS Critical Security Controls
* Nigeria Data Protection Act (NDPA) 2023

> **Portfolio note:** This repository is intended as a professional representation of the assessment methodology, risk-management approach, and security recommendations. Sensitive operational information, detailed infrastructure information, credentials, exploitable technical details, and restricted evidence are intentionally excluded.

## Risk Management Approach

A **5 × 5 likelihood-impact risk matrix** was used to evaluate identified risks.

### Likelihood

| Rating | Description    |
| ------ | -------------- |
| 1      | Rare           |
| 2      | Unlikely       |
| 3      | Possible       |
| 4      | Likely         |
| 5      | Almost Certain |

### Impact

| Rating | Description |
| ------ | ----------- |
| 1      | Negligible  |
| 2      | Minor       |
| 3      | Moderate    |
| 4      | Major       |
| 5      | Critical    |

Risk scores were calculated using:

**Risk Score = Likelihood × Impact**

This approach was used to prioritise remediation and support management decision-making.

### Year 2 — Security Operations Enhancement

Focus areas included:

* Red/Purple Team exercises
