# Executive Summary

## Cybersecurity Assessment — Defence Intelligence College (DIC)

**Project:** CCC299 Capstone Project
**Prepared by:** Adeshina Kolawole Tajudeen

---

## 1. Overview

This project involved a structured cybersecurity and enterprise risk assessment designed to evaluate security governance, cybersecurity controls, physical-security considerations, human-factor risks, publicly available information, and organizational resilience.

The assessment applied a risk-based methodology and referenced:

* NIST Cybersecurity Framework (CSF) 2.0
* ISO/IEC 27001:2022
* CIS Controls
* Nigeria Data Protection Act (NDPA) 2023

---

## 2. Assessment Results

The assessment identified **10 principal security findings**.

| Risk Level | Findings |
| ---------- | -------: |
| Critical   |        0 |
| High       |        3 |
| Medium     |        5 |
| Low        |        2 |
| **Total**  |   **10** |

The overall residual risk posture was assessed as **Moderate**.

The highest-scoring area was cybersecurity workforce capacity.

---

## 3. Key Risk Areas

The principal areas identified for continued improvement were:

### Cybersecurity Workforce

Specialist cybersecurity capability should continue to be strengthened through recruitment, training, certification, and practical security exercises.

### External Exposure

Continuous monitoring of externally visible assets can improve awareness of potential information and attack-surface risks.

### Security Validation

Periodic security assessments and controlled security-validation activities can help verify the effectiveness of existing controls.

### Physical Security

Continued assessment and optimization of physical-security processes can improve overall resilience.

### Governance

Security metrics, risk tracking, and compliance processes can benefit from greater automation and improved executive visibility.

---

## 4. Key Recommendations

The assessment recommended:

1. Strengthening cybersecurity workforce capability.
2. Improving external attack-surface monitoring.
3. Maintaining continuous security validation.
4. Enhancing security awareness.
5. Improving physical-security controls.
6. Strengthening network-security assurance.
7. Improving security monitoring and threat hunting.
8. Increasing governance and compliance automation.
9. Maintaining continuous risk assessment.
10. Establishing measurable cybersecurity performance indicators.

---

## 5. Strategic Roadmap

The recommended improvement program was divided into three phases.

| Phase      | Focus                                     |
| ---------- | ----------------------------------------- |
| **Year 1** | Strengthen cybersecurity foundations      |
| **Year 2** | Expand security validation and monitoring |
| **Year 3** | Automate and mature security governance   |

This phased approach allows security improvements to be prioritized according to risk while supporting long-term cybersecurity maturity.

## 8. Conclusion

The assessment demonstrated the importance of a layered, risk-based approach to cybersecurity.

The results provided a structured view of existing security capabilities and identified areas for continued improvement in workforce capability, external exposure management, security validation, governance, and resilience.

The resulting roadmap provides a practical framework for progressing from assessment findings to measurable cybersecurity improvements.
