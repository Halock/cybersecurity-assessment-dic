## 1. Executive Summary

This project involved a structured cybersecurity and enterprise security-risk assessment of Defence Intelligence College (DIC).

The assessment examined cybersecurity governance, technical and operational controls, physical-security considerations, human-factor risks, publicly available information, and organizational resilience.

The assessment used a risk-based methodology and referenced recognized cybersecurity frameworks and standards, including:

* NIST Cybersecurity Framework (CSF) 2.0
* ISO/IEC 27001:2022
* CIS Controls
* Nigeria Data Protection Act (NDPA) 2023

The assessment identified **10 security findings**:

| Risk Level | Findings |
| ---------- | -------: |
| Critical   |        0 |
| High       |        3 |
| Medium     |        5 |
| Low        |        2 |
| **Total**  |   **10** |

The overall residual risk posture was assessed as **Moderate**.

The most significant improvement area identified was cybersecurity workforce capacity. Other areas included external attack-surface visibility, continuous security validation, physical-security optimization, network-security assurance, and governance automation.

# 4. Assessment Methodology

The assessment combined multiple security-assessment techniques.

### Documentation Review

Security policies, procedures, governance documentation, and related organizational materials were reviewed.

### Interviews

Structured discussions were used to understand security practices, responsibilities, challenges, and organizational processes.

### Physical-Security Review

General physical-security controls and security-management processes were assessed.

### Cybersecurity Control Review

Security controls covering authentication, network security, endpoint protection, monitoring, and incident response were considered.

### Human-Factor Assessment

Security awareness, authentication practices, incident reporting, and workforce capability were evaluated.

### OSINT Assessment

Publicly available information was reviewed to identify potential information-exposure risks.

### Risk Analysis

Identified findings were evaluated using likelihood and impact to determine their relative risk levels.

---

# 5. Risk Assessment Methodology

A **5 × 5 likelihood-impact risk matrix** was used.

### Risk Calculation

**Risk Score = Likelihood × Impact**

### Likelihood

| Score | Description    |
| ----: | -------------- |
|     1 | Rare           |
|     2 | Unlikely       |
|     3 | Possible       |
|     4 | Likely         |
|     5 | Almost Certain |

### Impact

| Score | Description |
| ----: | ----------- |
|     1 | Negligible  |
|     2 | Minor       |
|     3 | Moderate    |
|     4 | Major       |
|     5 | Critical    |

### Risk Classification

| Score | Risk Level |
| ----: | ---------- |
|   1–4 | Low        |
|   5–9 | Medium     |
| 10–16 | High       |
| 17–25 | Critical   |

# 9. Key Recommendations

The assessment recommended a phased security-improvement program focused on:

### Cybersecurity Workforce

* Strengthen specialist cybersecurity staffing.
* Expand professional development and certification.
* Establish practical threat-hunting capabilities.
* Improve cybersecurity workforce retention.

### External Attack Surface

* Establish continuous monitoring of publicly exposed assets.
* Monitor changes to public-facing systems.
* Improve visibility of externally exposed information.
* Strengthen protection against phishing and impersonation risks.

### Security Validation

* Conduct periodic security assessments.
* Introduce structured red-team and security-validation activities.
* Validate security controls continuously rather than relying solely on periodic reviews.

### Physical Security

* Optimize surveillance coverage.
* Improve protection of ICT infrastructure.
* Modernize visitor-management processes.

### Governance

* Improve security metrics and executive reporting.
* Increase automation of risk and compliance management.
* Maintain continuous review of security policies and controls.
