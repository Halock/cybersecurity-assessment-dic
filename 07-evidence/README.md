## Overview

This repository presents a sanitized professional portfolio version of a cybersecurity assessment conducted as part of the CCC299 capstone project.

The assessment examined cybersecurity risk, physical security, human factors, governance, compliance, and organizational resilience.

The portfolio demonstrates how security observations can be translated into:

* Structured security findings
* Enterprise risk analysis
* Risk treatment priorities
* Security framework mappings
* Compliance considerations
* Strategic security improvements
* Executive-level recommendations

Sensitive operational information and detailed security evidence have intentionally been excluded from the public repository.

## Methodology

The assessment used a combination of:

1. Physical security assessment
2. Cybersecurity assessment
3. Stakeholder interviews
4. Documentation review
5. Passive OSINT
6. Risk analysis
7. Security framework mapping

A **5×5 likelihood-impact risk matrix** was used to classify findings.
